# Sistema de Gestão de Espaços para Eventos

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema para gerenciamento de espaços destinados a eventos.

A aplicação foi criada para auxiliar no controle de reservas, clientes, usuários e informações relacionadas aos eventos, substituindo processos manuais e proporcionando uma organização mais eficiente dos dados.

## Objetivo

Desenvolver uma solução simples para apoiar o gerenciamento de espaços para eventos, facilitando o cadastro de informações e o controle das reservas realizadas.

## Funcionalidades

- Cadastro de clientes
- Cadastro de usuários
- Gerenciamento de reservas
- Controle de lotação dos eventos
- Organização das informações dos espaços e eventos

## Tecnologias utilizadas

- Java 17 (JDK 17)
- IntelliJ IDEA
- Programação Orientada a Objetos (POO)

## Estrutura do projeto

Principais entidades:

- Cliente
- Usuário
- Reserva
- Lotação
